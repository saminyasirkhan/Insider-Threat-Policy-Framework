# 🛡️ Insider Threat Policy Framework

Designed a risk-based security governance framework to mitigate insider compromise within a remote-first organisation. The project analyses organisational control failures and develops layered security policies focused on prevention, detection, and response.

The framework addresses weaknesses in identity verification, privilege management, behavioural monitoring, and incident response, applying industry guidance from NIST and ISO-aligned security practices.

## Key Areas Covered

🔐 Identity Verification & Trusted Onboarding

- Identity Assurance Levels (IAL)
- Authenticator Assurance Levels (AAL)
- Remote employee verification
- Deepfake hiring and identity fraud risks

👥 Access Control & Privilege Management

- Role-Based Access Control (RBAC)
- Principle of Least Privilege
- Segregation of Duties
- Zero Trust access concepts

📊 Continuous Monitoring & Insider Detection

- Insider threat governance
- Audit logging and accountability
- Behavioural anomaly detection
- Risk-based monitoring strategies

🚨 Incident Response & Containment

- Account isolation procedures
- Forensic logging retention
- Incident response planning
- Post-compromise containment

📈 Risk-Based Prioritisation

- Defence-in-depth strategy
- Control implementation roadmap
- Organisational risk reduction
- Policy interdependency analysis
